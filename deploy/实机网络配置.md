# 实机四板网络配置说明（RM2027 四机集群）

四台 LubanCat-3（RK3576 8+64G，WiFi 套餐）+ 一台地面站笔记本，全部通过
地面站热点（或同一台路由器）组成星型局域网，ROS2 Humble + CycloneDDS 单播通信。

## 1. 拓扑与 IP 规划

```
                 ┌───────────────────┐
                 │  地面站笔记本      │
                 │  192.168.10.1     │  RViz / swarm_coordinator
                 │  （开热点）        │
                 └─────────┬─────────┘
                           │ WiFi（5GHz 优先，信道固定）
        ┌──────────┬───────┴──────┬──────────┐
        │          │              │          │
   ┌────┴───┐ ┌────┴───┐    ┌────┴───┐ ┌────┴───┐
   │ uav1   │ │ uav2   │    │ uav3   │ │ uav4   │
   │ .10.11 │ │ .10.12 │    │ .10.13 │ │ .10.14 │
   └────────┘ └────────┘    └────────┘ └────────┘
   每板跑：MicroXRCEAgent(serial→飞控) + algorithm.launch（OpenVINS、深度、规划、控制）
```

| 角色   | 主机名  | 静态 IP        |
|--------|---------|----------------|
| 地面站 | ground  | 192.168.10.1   |
| 板 1   | uav1    | 192.168.10.11  |
| 板 2   | uav2    | 192.168.10.12  |
| 板 3   | uav3    | 192.168.10.13  |
| 板 4   | uav4    | 192.168.10.14  |

> 机号约定：板子静态 IP 末位 −10 = 机号（.11→1 号机，以此类推）。
> `start_onboard.sh N` 的机号参数必须与该板 IP 对应。

## 2. 静态 IP 配置（netplan）

LubanCat 出厂 Ubuntu 22.04 用 netplan 管理网络。编辑
`/etc/netplan/01-static-wifi.yaml`（文件名不冲突即可）：

```yaml
network:
  version: 2
  wifis:
    wlan0:
      dhcp4: no
      addresses: [192.168.10.11/24]        # uav2~4 分别改 .12/.13/.14
      gateway4: 192.168.10.1
      nameservers:
        addresses: [192.168.10.1, 8.8.8.8]
      access-points:
        "RM27-SWARM":                      # 地面站热点 SSID
          password: "你的热点密码"
```

应用：

```bash
sudo netplan apply
ip addr show wlan0        # 确认拿到静态 IP
```

地面站（Ubuntu 笔记本开热点）：热点配置里把 IPv4 方式设为「共享给其他计算机」，
并手动把热点接口地址固定为 192.168.10.1/24；或者在热点的
NetworkManager 配置里 `ipv4.addresses=192.168.10.1/24`。

## 3. /etc/hosts（五台机器同一份）

```bash
sudo tee -a /etc/hosts <<'EOF'
192.168.10.1   ground
192.168.10.11  uav1
192.168.10.12  uav2
192.168.10.13  uav3
192.168.10.14  uav4
EOF
```

顺手把每块板子的主机名也改了（`sudo hostnamectl set-hostname uavN`），
排查日志时一眼能认出是哪台。

## 4. DDS 环境（五台机器同一份配置）

每台机器：

```bash
# setup_env.sh onboard 已安装 CycloneDDS RMW
sudo apt install ros-humble-rmw-cyclonedds-cpp

# 把 deploy/cyclonedds.xml 拷到固定位置，例如 ~/origin_drone_27/deploy/cyclonedds.xml
# 然后写进 ~/.bashrc：
export ROS_DOMAIN_ID=42
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
export CYCLONEDDS_URI=file:///home/cat/origin_drone_27/deploy/cyclonedds.xml
```

要点（已在 cyclonedds.xml 注释中详述）：
- `AllowMulticast=false` + 显式 Peers 单播列表——WiFi 多播不可靠，这是稳定发现的关键；
- 五台机器用**同一份** cyclonedds.xml；改 IP 规划只改 Peers 一节；
- `ROS_DOMAIN_ID=42` 五台必须一致，和实验室其他 ROS 设备隔离。

## 5. 时间同步（chrony）

VIO、多机避障对时间敏感，五台机器时钟必须对齐。

地面站（做时间源）：

```bash
sudo apt install chrony
# /etc/chrony/chrony.conf 追加：
#   local stratum 8
#   allow 192.168.10.0/24
sudo systemctl restart chrony
```

每块板子：

```bash
sudo apt install chrony
# /etc/chrony/chrony.conf：注释掉默认 pool，加一行：
#   server 192.168.10.1 iburst
sudo systemctl restart chrony
chronyc tracking        # 确认 Reference ID 指向地面站
```

## 6. 三条纪律（务必遵守）

1. **带宽**：图像 / 点云（`/uavN/d435i/*`、`/uavN/vio_cam*/image*`、任何
   PointCloud2）只允许在板子内部订阅，**绝不跨网**。跨网只放行位姿
   （odometry）、状态（state）、目标点（waypoint/goal）、报警这类 KB/s 小话题。
   一张 640×480 深度图 @15Hz ≈ 9MB/s，一路就能把 WiFi 打满。
2. **断网自保**：offboard 节点加看门狗——航点 / 指令超过 3 秒没更新就原地悬停，
   绝不继续执行过期指令；ET08 遥控器的接管通道保持常开，任何时候能一把抢回来。
3. **起停顺序**：先开地面站 DDS 环境，再逐块板上电起 `start_onboard.sh N`；
   收场先落飞机、停板子节点，最后关地面站。

## 7. 板上软件准备

板子上**不装** Gazebo / PX4 SITL，只跑实机节点。工作空间拷到板上后执行
`./setup_env.sh onboard`，该模式准备 OpenVINS、px4_msgs release/1.14、MicroXRCEAgent 和工作空间。

另需：

```bash
sudo apt install ros-humble-realsense2-camera   # D435i 驱动
```

飞控串口接板子 UART1（ttyS1，921600），飞控侧 PX4 参数 `EKF2_EV_CTRL=15`
（开外部视觉融合，VIO 位姿灌进 EKF2）。

## 8. 启动与验证顺序

```bash
# 地面站
ping 192.168.10.11       # ① 五台互 ping 全通
ros2 run demo_nodes_cpp talker   # ② 地面站 talker

# 板 uav1（另开终端）
ros2 run demo_nodes_cpp listener # 能收到 → DDS 单播发现 OK

# 板上正式起飞
CALIBRATION_DIR=~/calibration/uav1 TARGET_SYSTEM=1 ./deploy/start_onboard.sh 1
# 脚本不会自动解锁；验证完整链路后再调用 start_mission 服务。

# 地面站逐机确认链路
ros2 topic echo /uav1/state      # ③ 看到心跳 → 该机链路 OK
ros2 topic echo /uav2/state      # 逐台加，一次只加一架
```

验证顺序：**互 ping → demo talker/listener → echo /uavN/state → 逐架加入 → 四机齐飞**。
任何一步不通，先查 `ROS_DOMAIN_ID` / `CYCLONEDDS_URI` 是否生效
（`env | grep -E 'ROS_DOMAIN|CYCLONE|RMW'`），再查 cyclonedds.xml 的网卡名和 Peers。
